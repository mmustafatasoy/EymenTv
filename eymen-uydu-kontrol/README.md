# EYMEN TV v0.11 — Kanal Listesi

Android TV / Whale OS / Vestel cihazlarda erişilebilen TV Input Framework kanal kayıtlarını okuyan kanal listesi ve canlı yayın deneme uygulamasıdır.

- Sağ üst köşedeki şeffaf 3D EYMEN TV logosu yayın süresince kalır.
- Üstte EYMEN TV + www.atasoyyazilim.com, kanallar açıkken saatte bir 15 saniye görünür.
- Alt bant aile fotoğrafı, telefon numarası, isim ve reklam animasyonları kaldırıldı.
- Kanal listesi, 10'lu kumanda sayfaları, düzenleme, favori, toplu silme/geri getirme, EPG ve ses izleri korunur.
- MENU → Seçenekler → Saatlik logo/web göster (test) ile görseli erken test edebilirsiniz.

**Geliştirici:** Atasoy Yazılım

**Sürüm:** v0.11 (Android API 26+ hedef; gerçek tuner izni cihaz üreticisine bağlı)

**APK:** [GitHub Releases v0.11](https://github.com/mmustafatasoy/EymenTv/releases/tag/uydu-tv-v0.11).
